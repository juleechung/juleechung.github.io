I refined the Spot pipeline around camera recording, gripper-camera views, object grounding, and evaluation. The current system is moving toward a repeatable ablation study rather than a single demo.

The implementation now includes a clearer separation between task conditions and shared utilities. The task scripts cover text+gesture, voice+gesture, clarification, gaze, camera repositioning, full movement, and an exocentric view. The shared utilities handle Spot connection, camera capture, session logging, speech, confidence fusion, gesture estimation, and safety controls.

I also began comparing local and frontier model behavior for visual grounding, including experiments with local model tooling such as [Ollama](https://ollama.com) and [Gemma](https://ai.google.dev/gemma). The next step is to use the logs and recordings to evaluate task completion, number of clarifying questions, time to confidence, and confidence at the decision point. This should make it possible to describe not only whether the system works, but which modalities appear to help most.
