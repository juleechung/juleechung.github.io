I refined the benchmark visualization so model outputs could be compared on a single frame. The latest overlay shows where each model points, whether it answers directly or asks a question, and how the project's YOLO-based system localizes the referred object.

<!-- Media: YOLO grounding comparison image -->

This image captures the kind of ambiguity the project is trying to study. The instruction "pick that up" is paired with a pointing gesture toward several similar bottles on the floor. Some model conditions ask which bottle is intended, while others choose a coordinate directly. The project's current system combines object detection and pointing geometry, producing a selected referent with a fused confidence score.

The next step is to turn these comparisons into a cleaner evaluation table. I want to track whether each condition picks the correct referent, asks an appropriate clarifying question, how long it takes, and whether the result is usable for a physical robot action. That should make the final analysis more grounded than a simple success/failure demo.
