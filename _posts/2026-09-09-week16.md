I refined the benchmark visualization so model outputs could be compared on a single frame. The latest overlay shows where each model points, whether it answers directly or asks a question, and how the project's own [YOLOv8n-pose and YOLO-Worldv2 pipeline](https://github.com/juleechung/multimodal_hri/tree/main/ablation_YOLO) localizes the referred object.

![Four models answering the instruction pick that up on one frame, with their chosen points overlaid]({{ site.baseurl }}/images/deictic-grounding-model-comparison.jpg)

*One frame, four systems. Given "pick that up" and a pointing gesture toward three similar bottles, Gemini Robotics-ER asks which bottle is meant, GPT-5 and Molmo2-ER commit to coordinates, and the project's YOLO pipeline returns a boxed referent at a fused confidence of 0.74.*

This image captures the kind of ambiguity the project is trying to study. The instruction "pick that up" is paired with a pointing gesture toward several similar bottles on the floor. Some model conditions ask which bottle is intended, while others choose a coordinate directly. The project's current system combines YOLO-Worldv2 object detection and YOLOv8n-pose pointing geometry, producing a selected referent with a fused confidence score.

The next step is to turn these comparisons into a cleaner evaluation table. I want to track whether each condition picks the correct referent, asks an appropriate clarifying question, how long it takes, and whether the result is usable for a physical robot action. That should make the final analysis more grounded than a simple success/failure demo.
