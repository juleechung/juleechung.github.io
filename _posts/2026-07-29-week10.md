I designed an initial GUI for working with Spot and inspecting deictic grounding results. The interface brought together camera feeds, candidate referents, pointing angle, confidence scores, and the robot's proposed interpretation.

<!-- Media: Initial GUI layout image -->

This week was about making the system easier to debug and safer to run. A GUI made it possible to see what Spot was seeing, whether a person was detected, which object was being treated as the referent, and how the gesture likelihood was being calculated. I added overlays so the referred object could be boxed in red, with the angle used in the gesture model shown alongside the result.

The interface also started to support the experimental workflow: record a command, capture synchronized camera frames, run grounding, display confidence, and decide whether the robot should act or ask a question. Making those steps visible helped turn the project from a collection of scripts into a testable HRI system.
