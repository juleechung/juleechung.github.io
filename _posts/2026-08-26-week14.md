I expanded the GUI into a more complete operator interface for the ablation study. The latest layout includes Spot's body cameras, gripper RGB and depth views, command recording, confidence readout, clarification dialogue, walk controls, arm controls, gripper controls, and E-Stop.

![Updated Spot operator interface during a sweep, showing candidate crops and the running log]({{ site.baseurl }}/images/spot-gui-v2.jpg)

*The updated operator interface mid-sweep, with the candidate crops and the running log visible.*

![Gripper depth frame showing a person as a blue point cloud with the nearest bottle in cyan]({{ site.baseurl }}/images/spot-gripper-depth-frame.jpg)

*A gripper depth frame from a recorded session. The person registers as a blue point cloud and the nearest bottle stands out in cyan, captured alongside the gripper's colour view.*

The gripper camera became especially important because it gives a sharper color view than the body fisheye cameras. I added support for gripper RGB and depth feeds so the system can show the operator what Spot is using for grounding, while still recording the session for later review. The interface also keeps motion opt-in: movement requires enabling motion, powering the robot, and confirming planned actions before Spot walks or uses the arm.

<p>I also changed what the interface shows while it waits. A voice command and a sweep both play out over a few seconds, and I had no way to tell whether the whole sentence or the whole gesture had been captured. The button now reads &ldquo;listening&rdquo; with a countdown while the mic and the gesture window are open, so I can see exactly when to start and when to stop. It then switches to &ldquo;thinking&rdquo; while the models run, which on CPU can take tens of seconds. Without that there is no way to tell whether the system is working or has stalled.</p>

This version made the project feel closer to an experiment. The GUI now supports repeated runs, typed or spoken answers, live overlays, camera recording, and session logs. Those details are not glamorous, but they are what make the difference between an interesting interaction and a study that can be evaluated.
