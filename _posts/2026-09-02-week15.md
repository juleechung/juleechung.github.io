I started building a replay-based benchmark so different models could be tested on the same saved frames. This made it possible to compare local and frontier models without needing a new live Spot session for every experiment.

The benchmark uses captured grounding frames and asks each model to identify the referred object under different conditions: free choice, pointing-only, and pointing with the option to ask a clarifying question. I tested models such as GPT, Gemini, and Molmo, alongside the project's own YOLO-based pipeline.

This was useful because model behavior varied in exactly the ways the project cares about. Some models selected a plausible object quickly but confidently. Others asked a clarifying question when several referents were close together. The benchmark gives the project a way to compare not just accuracy, but whether a system knows when it should hesitate.
