I started building a replay-based benchmark so different models could be tested on the same saved frames. This made it possible to compare local and frontier models ([GPT-5](https://openai.com/), [Gemini Robotics-ER](https://deepmind.google/technologies/gemini-robotics/) and [Molmo2-ER](https://molmo.allenai.org/)) without needing a new live Spot session for every experiment. The replay benchmark lives in [benchmark](https://github.com/juleechung/multimodal_hri/tree/main/benchmark), and the frontier-model arm of the study in [ablation_VLM](https://github.com/juleechung/multimodal_hri/tree/main/ablation_VLM).

I changed to a replay-based benchmark because live runs cannot be compared with each other. The scene moves, the lighting shifts, and my gesture is never quite the same twice, so a difference between two models could just as easily be a difference between two moments. Passing one frame across models makes a comparison possible. The frames come from the live sessions in the previous weeks, so building the live system first was helpful.

The benchmark uses captured grounding frames and asks each model to identify the referred object under three conditions. Free choice, pointing only, and pointing with the option to ask a clarifying question. Each model was tested alongside the project's own [YOLOv8n-pose and YOLO-Worldv2 pipeline](https://github.com/juleechung/multimodal_hri/tree/main/ablation_YOLO).

This was useful because model behavior varied in exactly the ways the project cares about. Some models selected a plausible object quickly and confidently. Others asked a clarifying question when several referents were close together. The third condition, which lets the model ask a clarifying question instead of answering, is the most interesting. It tests whether a frontier model will decline to commit when the scene is ambiguous, which my own pipeline does by asking whenever more than one candidate survives the pointing cone. The benchmark gives the project a way to compare accuracy and also whether a system knows when it should stop and ask.
