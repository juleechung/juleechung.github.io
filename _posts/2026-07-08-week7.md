I explored whether Spot simulation in [MuJoCo](https://mujoco.org/) would be useful for the project. I set up the Spot arm model from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie), added camera views, placed a target object in the scene, and ran an early visual grounding test.

MuJoCo was useful for understanding robot assets, camera placement, and basic simulation setup. I learned that the DeepMind Menagerie Spot model did not include the camera configuration I needed by default, so I added egocentric camera views and tested a simple instruction such as "straighten that out." The first VLM test produced an interesting result: it understood the action concept, but misidentified the visible arm/gripper as an object in the scene.

This made the limitation of simulation clear. The question I am studying is physically and socially involved: it depends on real camera distortion, human gesture, robot embodiment, object occlusion, and the back-and-forth of clarification. Simulation was helpful for orientation, but the project needed to move toward a physical experiment with Spot.
