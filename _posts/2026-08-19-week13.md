I began moving from the earlier MediaPipe-based prototype toward a more robust perception stack. The main direction was to test [YOLOv8n-pose](https://docs.ultralytics.com/tasks/pose/) for person and pose detection and [YOLO-Worldv2](https://github.com/AILab-CVC/YOLO-World) for open-vocabulary semantic object detection, while keeping the ablation design intact.

The motivation was practical. MediaPipe worked for close, clean views, but it struggled when the person was small, far away, or only partly visible in Spot's cameras. Because pointing is central to the project, missed or unstable body keypoints can make the entire grounding pipeline fragile. The division of labour that came out of this is that YOLO owns the coordinates and the VLM owns the semantics, so the detector proposes boxes for whatever noun it is given and gemma4 decides what those boxes actually are. I started looking at [YOLOv8n-pose](https://github.com/ultralytics/ultralytics) as a more reliable way to detect a person, estimate skeleton keypoints, and draw the pointing ray across live camera feeds.

<p>That leaves two ways forward. The first is that the robot asks when it cannot tell. If it detects three bottles and the ray does not clearly separate them, it describes what it sees and puts the question back to the person. The second is to give the person a more precise way to point, such as a headset that also gives the robot an egocentric view of what the user is looking at, with its own display where the user can aim at the object from their own point of view. The next two runs test the first option. They use the same scene and the same command, and the only thing that changes is whether I answer the question the robot asks.</p>

This week also clarified the difference between building a demo and building a study. A demo only needs one successful run; a study needs the same pipeline to behave consistently across conditions. That pushed the code toward shared utilities, clearer task boundaries, and logging that can support later evaluation. The rebuilt arm lives in [ablation_YOLO](https://github.com/juleechung/multimodal_hri/tree/main/ablation_YOLO), replacing [ablation_MEDIAPIPE](https://github.com/juleechung/multimodal_hri/tree/main/ablation_MEDIAPIPE).
