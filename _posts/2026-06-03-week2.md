This week focused on literature review and project framing. I read work on language-and-gesture grounding, instruction ambiguity, deictic gesture datasets, and multimodal robot perception.

Several papers helped shape the project direction:

- **[LEGS-POMDP](https://arxiv.org/abs/2603.04705)** (LanguagE and Gesture-guided Object Search in Partially Observable Environments) is a modular POMDP system that integrates language, gesture, and visual observations for open-world object search. Its [results](https://arxiv.org/html/2603.04705v1#S5) map closely onto this project: language alone is insufficient for deictic reference in robot instruction, combining language and gesture significantly improves resolution accuracy, and the way the pointing gesture is encoded meaningfully changes performance.
- **[Ask-to-Clarify](https://arxiv.org/html/2509.15061v1)** treats the passive pattern of receiving an instruction and executing it as the problem, since without feedback it fails when instructions are ambiguous. It resolves ambiguity through multi-turn dialogue, pairing a diffusion model for action generation with a connection module that conditions that model on the VLM's output.

For datasets, evaluation, and annotation I looked at:

- **[EgoPoint-Bench](https://arxiv.org/abs/2604.21461)** (2026): frontier models hover around 60% on egocentric pointing and lean on visual proximity rather than gesture direction, a failure the authors call referential hallucination.
- **[EgoPointVQA / HINT](https://arxiv.org/abs/2603.12533)** (2026): 4,000 synthetic and 400 real deictic gesture videos already labelled with ground-truth referents. HINT interleaves hand keypoint tokens with video and reaches 68.1% on deictic gesture QA.
- **[EcoG-Bench](https://arxiv.org/abs/2603.07966)** (2026): targets the gap in co-speech gesture grounding.
- **[EgoExoBench](https://arxiv.org/abs/2507.18342)** (2025): MLLMs fail at cross-perspective alignment even when they do well on single-view tasks.
- **[NatSGD](https://www.snehesh.com/natsgd/)** (2024): an HRI dataset with robot-egocentric and third-person views of the same interaction, synchronised.
- **[NatSGLD](https://dl.acm.org/doi/10.5555/3721488.3721628)** (2024): speech, gesture, logic, and demonstration for robot learning in natural HRI.
- **[GESRes](https://pmc.ncbi.nlm.nih.gov/articles/PMC12589646/)** (2025): a rich gesture annotation schema co-authored with Prof. Marsella, and my primary annotation reference. It separates abstract deictic from regular deictic.

A recurring takeaway was that language alone is weak for deictic instructions. Gesture helps, but only if the system represents the gesture carefully and understands where it lands in the scene. This pushed the project toward an ablation-style design to test what changes when speech, gesture, visual context, gaze, and clarification are added one at a time.
