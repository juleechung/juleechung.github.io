This week focused on literature review and project framing. I read work on language-and-gesture grounding, instruction ambiguity, deictic gesture datasets, and multimodal robot perception.

Several papers helped shape the project direction:

- **[LEGS-POMDP](https://arxiv.org/abs/2603.04705)** was especially useful because it treats language, gesture, and visual observations as separate signals that can be fused probabilistically for object search.
- **[Ask-to-Clarify](https://arxiv.org/abs/2509.15061)** helped frame ambiguity as something the robot should respond to through dialogue rather than silently guessing.

I also looked at work on gesture-based object search, along with EgoPointBench, EgoPointVQA/HINT, EcoG-Bench, EgoExoBench, NatSGD, NatSGLD, and GESRes as possible references for datasets, evaluation, and annotation.

A recurring takeaway was that language alone is weak for deictic instructions. Gesture helps, but only if the system represents the gesture carefully and understands where it lands in the scene. This pushed the project toward an ablation-style design to test what changes when speech, gesture, visual context, gaze, and clarification are added one at a time.
